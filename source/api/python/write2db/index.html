python.write2db

This module is used to create insert or update queries for a MySQL database. The module execute the queries in the target database and return the id of the row inserted or updated.

param file_path:

Path to the JSON file containing data to insert or update in a DB

type file_path:

str

raises ValueError:

when the query is not executed successfully

raises ValueError:

when keys are missing

raises ValueError:

when the input data is not properly formatted

raises ValueError:

when there are invalid method values in the table configuration

raises ValueError:

when the query retrieves more than one value

raises ValueError:

when table name is not found in configuration

returns:

json file with last id of the row inserted or updated

rtype:

str

python.write2db.format_sql_value(value) → str

Render a Python value as a SQL literal: NULL for empty/None, else a quoted, escaped string.

The NULL/value decision is made per-value, before quoting/escaping, so a value whose escaped content happens to end adjacent to its own closing quote can never be mistaken for an empty placeholder (which a post-hoc string search for “’’” could not tell apart).

python.write2db.execute_query(query: str, table_name: str, data_dict: Dict, table_conf, metadata_params) → Tuple[Any, Any]

This function execute the query in the target database, if the query is an insert query it will return the id of the row inserted. If the query is an update query it will return the id of the row updated. If the query is duplicated it will retrieve the id of the row.

Parameters:

  • query (str) – query to be executed in the target database

  • table_name (str) – table name to be used for the insert/update operation

  • data_dict (Dict) – dictionary containing key:values to be insert/update in the DB, used to retrieve the id of the row when the query is duplicated

Raises:

ValueError – raise an error when the query is not executed successfully

Returns:

id of the row inserted or updated

Return type:

int
