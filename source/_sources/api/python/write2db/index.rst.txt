python.write2db
===============

.. py:module:: python.write2db

.. autoapi-nested-parse::

   This module is used to create insert or update queries for a MySQL database.
   The module execute the queries in the target database and return the id of the row inserted or updated.

   :param file_path: Path to the JSON file containing data to insert or update in a DB
   :type file_path: str

   :raises ValueError: when the query is not executed successfully
   :raises ValueError: when keys are missing
   :raises ValueError: when the input data is not properly formatted
   :raises ValueError: when there are invalid method values in the table configuration
   :raises ValueError: when the query retrieves more than one value
   :raises ValueError: when table name is not found in configuration

   :returns: json file with last id of the row inserted or updated
   :rtype: str

.. py:function:: escape_value(value) -> str

   Escape a value for safe embedding inside a single-quoted SQL string literal.


.. py:function:: format_sql_value(value) -> str

   Render a Python value as a SQL literal: NULL for empty/None, else a quoted, escaped string.

   The NULL/value decision is made per-value, before quoting/escaping, so a value whose
   escaped content happens to end adjacent to its own closing quote can never be mistaken
   for an empty placeholder (which a post-hoc string search for "''" could not tell apart).

.. py:function:: retrieve_row_id(data_dict: Dict, table_name: str, table_conf, metadata_params) -> int

   If data is already inserted in the db, this function retrieves the id of the row using the
   data provided and the table name, it will retrieve the uniqueness constrain of the table and
   use it to retrieve the id of the row.

   :param data_dict: dictionary containing key:values to be insert/update in the DB
   :type data_dict: dict
   :param table_name: table name to be used for the insert/update operation
   :type table_name: str

   :returns: id of the row
   :rtype: int


.. py:function:: execute_query(query: str, table_name: str, data_dict: Dict, table_conf, metadata_params) -> Tuple[Any, Any]

   This function execute the query in the target database, if the query is an insert query it will
   return the id of the row inserted. If the query is an update query it will return the id of the
   row updated. If the query is duplicated it will retrieve the id of the row.

   :param query: query to be executed in the target database
   :type query: str
   :param table_name: table name to be used for the insert/update operation
   :type table_name: str
   :param data_dict: dictionary containing key:values to be insert/update in the DB, used to
                     retrieve the id of the row when the query is duplicated
   :type data_dict: Dict

   :raises ValueError: raise an error when the query is not executed successfully

   :returns: id of the row inserted or updated
   :rtype: int
